# tar

% archive

#plateform/linux #target/local #cat/UTILS 

## Create a tar containing files
```
tar cf <NAME>.tar <PATH>
```

## Extract the files from a tar
```
tar xf <tar_file>
```

## Create a tar with Gzip compression
```
tar czf <NAME>.tar.gz <PATH>
```

## Extract a tar using Gzip
```
tar xzf <FILE>
```
